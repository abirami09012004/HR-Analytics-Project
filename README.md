📊 HR Analytics & Workforce Attrition Dashboard

🚀 Project Overview
This project focuses on HR Analytics, analyzing employee data to understand attrition trends, departmental performance, and workforce demographics. The primary goal is to provide actionable insights to HR management for improving employee retention and workplace satisfaction.



🛠️ Tech Stack & Tools Used
* **Data Analysis & Processing:** Python / SQL / Excel
* **Visualization:** Power BI / Tableau / Data Analysis
* **Reporting:** PDF & PowerPoint Presentations

---

## 📈 Key Insights & Analysis
* **Employee Attrition Trends:** Identified critical factors leading to employee turnover.
* **Departmental Performance:** Analyzed performance metrics across various departments.
* **Demographics & Diversity:** Evaluated workforce distribution based on gender, race, and background.
* **Hiring Trends:** Tracked recruitment patterns and hiring velocity over time.

---

## 📁 Repository Structure
* reports -> Contains the detailed HR Analytics Report (PDF) and Presentation (PPTX).
* charts -> Visual exports of dashboards, KPI metrics, and department breakdowns.
